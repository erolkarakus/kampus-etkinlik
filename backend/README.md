# Kampüs Etkinlik Backend API

Bu servis, etkinlik verilerini REST mimarisiyle sunan Express tabanlı bir Node.js backend uygulamasıdır.

## Kurulum ve Çalıştırma

Projeyi çalıştırmak için:

```bash
# Bağımlılıkları kur
npm install

# Geliştirme modunda başlat
npm run dev

# Normal modda başlat
npm start
