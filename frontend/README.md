# Kampüs Etkinlikleri Yönetim Portalı (Sprint 6)

Bu proje Kampüs Etkinlikleri Yönetim Portalı vize projesidir.

## Canlı Demo (Vercel)
- https://erolkarakus-frontend.vercel.app

## Özellikler
- React Router DOM ile 10 adet sayfa rotası
- Context API ile global CRUD durum yönetimi (Ekle, Sil, Güncelle)
- Silme işleminde onay penceresi (`window.confirm`)
- Kategori filtreleme ve metin araması
- Form doğrulama ve hata bildirimleri
- Mobil uyumlu tablo-kart dönüşümü (Responsive CSS)
